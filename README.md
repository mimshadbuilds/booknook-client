# BookNook

BookNook is a modern community book-sharing platform that helps readers discover new titles, explore curated collections, and connect with a neighborhood of fellow book lovers.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- MongoDB
- Better Auth
- HeroUI
- shadcn/ui

## Key Features

1. Curated book discovery with featured arrivals, most-read picks, and category-based browsing.
2. Community-focused reading experience that encourages engagement around shared books and recommendations.
3. Personalized homepage sections for new arrivals, trending reads, and community-driven discovery.
4. Modern, responsive interface designed for seamless browsing across desktop and mobile devices.
5. Secure authentication and user-friendly book platform infrastructure to support a smooth digital library experience.
